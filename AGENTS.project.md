# PART-OUT — stay on this bench

This repo is a car workbench. Drop GLB. Spin. Snap vertices. Cut parts. L/R mirror. Export.

## Job

- Fused mesh → corner dots on real vertices → Cut.
- Named mesh → click → Cut. **Named** claims useful node names.
- **Door 2D** guesses a side-elevation door poster and snaps 4 verts. Then Cut. Then L/R.
- Ctrl/Cmd+Z undoes last dot, then mesh pick, then last part.

## Stay here

Edit `src/lib/workshop/*` and `src/components/workshop/*`. Do not clone wheen, ecctrl, or a driving stack. Do not ingest CAD-1000-hours or million-asset sets. Do not add a never-list.

A correction stays on the correction. Call the user Nat.

Built for 400–800 face cars; tolerate ~5k.
